# Практическая работа №2 — «Дерево вызовов и паттерн Стратегия»

**Курс:** Технология разработки программного обеспечения · лекция №7  
**Язык:** Python 3.9+ (без сторонних библиотек)

Реализован профилировщик, поддерживающий вложенные замеры времени и три взаимозаменяемые стратегии формирования отчётов.

## Реализовано

- **Node:** дерево вызовов с родителем, дочерними узлами, количеством вызовов, общим и собственным временем.
- **Profiler.section(name):** вложенный замер времени через with; родитель восстанавливается в finally даже при исключении.
- **@profiler.profile:** декоратор для измерения функций.
- **TableReport:** плоский отчёт по функциям с числом вызовов и временными характеристиками.
- **TreeReport:** иерархический отчёт с отступами.
- **JSONReport (ChromeTraceExporter):** экспорт событий для Perfetto в формате Chrome Trace.
- **Strategy:** Profiler.report(format) делегирует формирование отчёта выбранному объекту, без if/elif по форматам.
- **13 автоматических тестов:** вложенность, агрегация, собственное время, рекурсия, исключения, декоратор и форматы.

## Запуск

~~~bash
python main.py
python -m unittest discover -s tests -v
~~~

На Windows можно запустить run_windows.bat; на Linux/macOS — bash run_linux_mac.sh.

Дополнительные параметры:

~~~bash
python main.py --frames 10 --slow-frame 4 --trace results/my_trace.json
~~~

Программа симулирует загрузку уровня (~200 мс), затем 60 кадров, каждый из которых содержит update → physics и draw → shadows, sprites. На **31-м кадре** добавляется задержка 20 мс, чтобы показать всплеск на временной шкале.

В результате создаётся файл **results/trace.json** с 361 событием: 1 загрузка + 60 × (кадр, update, physics, draw, shadows, sprites). Замеры зависят от производительности компьютера. Вывод реального эталонного запуска приведён в results/console_output.txt.

## Временная шкала Perfetto

1. Откройте https://ui.perfetto.dev.
2. Выберите **Open trace file** → **results/trace.json** (создаётся при запуске).
3. Найдите 31-й кадр: он заметно длиннее соседних.
